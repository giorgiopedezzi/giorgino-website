# US05 — Running Project Deep Page

Build the dedicated page for the running application.

This is proof of thought, not a conventional portfolio case study.

## Core idea
The runner enlightens the data.

Without the runner, there is telemetry.
With the runner, the same telemetry acquires meaning.

AI/technology may do heavy implementation work; human judgment remains responsible for concept, constraints, priorities, validation and decisions.

## Suggested structure
1. The problem — too much telemetry / false certainty
2. What I decided not to build
3. Principles
   - signal over noise
   - flexible plans over false perfection
   - adaptation without losing the objective
   - assistance without surrender
   - runner remains at the center
4. The object — screenshots / visuals
5. How it was built — AI coding agents + human direction
6. What the visualization means
   - HR pink → red
   - long pause: runner collapses
   - short pause: runner jogs/bounces
   - human figure makes telemetry intelligible
7. Current state / living experiment

Do not invent product claims unsupported by the project/source material.
Do not embed/rebuild the entire running application inside this page.

Homepage stays a teaser; avoid a loud CTA.
